Before You Buy

Do I need to know anything technical?
No. Everything runs in Google Drive — Gmail, Sheets, Docs. If you can create a folder and rename a file, you can set this up. The guide is written specifically for people who want a working system, not a tech project.
What if I already have some of these documents?
Great — use them. The templates are designed to be replaced with your current documents if you have ones you prefer. The system works around your documents, not the other way around.
How long does setup actually take?
Most people complete the folder structure and bid tracker setup in 2–4 hours. The templates are ready to use immediately. You'll be fully operational the same day you buy.
Does this work for a small crew, not just solo techs?
Yes — the Google Drive structure is built with crew sharing in mind. Multiple people can access the same job folders, track the same bids, and use the same templates. The Tier 2 install includes crew-specific customization.
What's the difference between Tier 1 and Tier 2?
Tier 1 is the complete kit — you set it up yourself using the included guides. Tier 2 is us setting it up inside your actual Google account, personalized to your specific operation, with professional custom templates. Same system, different level of done-for-you.
What's your refund policy?
If you set it up and it genuinely doesn't deliver value, contact us. We stand behind the product. Our goal is repeat and referral business — that only happens if you're satisfied.
